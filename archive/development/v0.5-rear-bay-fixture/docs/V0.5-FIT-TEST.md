# v0.5 rear-bay fit test

v0.5 replaces the incompatible iodeo donor cassette with an open guide bay for
the owner's populated ESP Minitel V2 **JST** board. This is the physical fit
gate before the bay is incorporated into a complete Minitel-shaped body.

## Measured inputs

| Input | Value | Source |
|---|---:|---|
| PCB long dimension | 46.9 mm measured; 47.105 mm model | Owner measurement and v2.2 Gerber |
| PCB depth | 36.1 mm measured; 36.218 mm model | Owner measurement and v2.2 Gerber |
| Populated height | 10.4 mm | Bottom ESP32 module to top JST connector |
| USB-C outer edge to relaxed loop | 60.0 mm | Owner-selected routing envelope |
| PCB thickness | 1.60 mm | Nominal |

The visual cable reference is 5.0 mm in diameter because the cable diameter is
not measured yet. The fixture is open above the guide and therefore does not
trap a slightly larger cable.

## Mechanical layout

The connected JST end enters first from the open rear. The irregular nose and
connector pass between the guides. The broad USB-C edge then enters two flared
C-channels. Only about 1.0 mm of each bare PCB edge is carried; there is no
carrier plate, snap nub or mounting-hole pin.

The PCB ends with USB-C and RESET at the open rear. The connected cable turns
in front of the PCB and returns above the right guide. A removable retainer
slides downward after routing the cable. Its centre remains open, so the DIN
plug never has to pass through a printed hole. One narrow finger stops the PCB
from sliding backwards.

## Creality K2 print baseline

- 0.4 mm nozzle.
- 0.20 mm fixed layer height.
- 3 walls.
- PLA for the first fit test.
- No supports.
- No scaling or automatic hole compensation.
- Print each STL in its exported orientation.

The 1.6 mm PCB uses a 2.2 mm vertical slot: 0.30 mm clearance above and below.
The 47.105 mm Gerber width has 0.35 mm side clearance per side. The supporting
lip is 1.0 mm deep and remains printable with a 0.4 mm nozzle.

`WDTY v0.5` is enclosed in the front bridge as a 0.60 mm internal void. At the
0.20 mm baseline it occupies three layers, with three solid layers below and
three above. It is visible in slicer layer preview but not on the exterior.
Adaptive layer height changes the number of watermark layers.

## Test order

1. Print `minitel_guide_coupon_v0.5-test.stl` first.
2. Insert only the broad USB-C edge of the unpowered PCB. It should move with
   light finger pressure and without bending the board.
3. If the coupon passes, print `minitel_rear_bay_v0.5-test.stl` and
   `minitel_rear_retainer_v0.5-test.stl`.
4. Connect JST before insertion. Feed the PCB forward, form the relaxed cable
   turn, lay the return above the right guide and install the retainer from
   above.
5. Verify USB-C plug access and RESET operation while the board is unpowered.

Do not force a tight coupon. Report whether it is loose, correct, or tight and,
if possible, measure the printed slot and PCB thickness.

## CAD checks

- All three printable STLs have zero nonmanifold edges.
- The exact Gerber board plus the conservative 10.4 mm component envelopes were
  sampled at 49 positions over 48 mm of rearward travel, in 1 mm increments.
  No intersection with the fixture was found.
- The installed 5.0 mm cable reference has no intersection with the fixture.
- The installed retainer has no intersection with the PCB, component envelopes
  or cable reference.
- These checks validate the modelled envelopes. A physical coupon remains the
  authority for printer tolerance and unmeasured component placement.

Rebuild and verify from the repository root:

```sh
openscad --export-format binstl -D 'part="fixture"' -o stl/v0.5/minitel_rear_bay_v0.5-test.stl src/minitel_v05_fit_test.scad
openscad --export-format binstl -D 'part="coupon"' -o stl/v0.5/minitel_guide_coupon_v0.5-test.stl src/minitel_v05_fit_test.scad
openscad --export-format binstl -D 'part="retainer"' -o stl/v0.5/minitel_rear_retainer_v0.5-test.stl src/minitel_v05_fit_test.scad
python3 tools/check_v05_clearance.py
python3 tools/review_v05.py
```
